# 关于「说人话」

一个新人进入大厂后，往往要在「黑话考试」里裸考：会上听到 OKR、MVP、「对齐一下颗粒度」「先找抓手再落地」，文档里满是 PRD、埋点、灰度、北极星指标——每一个字都认识，连起来就听不懂。

**「说人话」要做的就是这件事：把职场黑话和术语翻译成人话。**

## 它有什么不一样

市面上已有一些相关项目，但各有明显缺口：

- **纯词表类**（如互联网黑话词汇表）：只有词没有解释，无法查询。
- **AI 批量生成的词典**：词条多但质量参差，没有使用场景，也没有好的查阅体验。
- **拼音缩写翻译工具**（如 nbnhhsh）：解决的是 yyds、xswl 这类网络缩写，不覆盖职场语义词。
- **直接问 AI**：方便，但会一本正经地编造小众黑话的含义，也没有沉淀和社区。

「说人话」的差异化：

1. **三层内容体系**：中英缩写 → 黑话行话 → 业务/研发概念，按新人真实困惑组织。
2. **词条有结构**：一句话解释、详细解释、真实会议室例句、常见误解、相关词条——不是一坨文字。
3. **数据与产品分离**：词条全部存在 JSON 里，站点只是第一个「壳」，未来插件、飞书/企微机器人、API 都能直接复用同一份数据。
4. **人人可贡献**：发 Issue 就能收词，提 PR 就能上榜，校验脚本保证数据质量。

## 数据从哪来

词条解释由贡献者人工编写，追求「大白话 + 真实语境」，不搬运百科腔。种子词条由首批贡献者根据真实工作经验编写，欢迎指正和补充。
